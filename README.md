# Stock Signal Scanner

Локальное приложение для мониторинга акций: тикеры → цены → стратегия → сигнал → Telegram.

## Запуск

```powershell
python app.py
```

Откройте:

```text
http://127.0.0.1:8787
```

## Хостинг

### Cloudflare

Для переноса серверной части в Cloudflare добавлен отдельный Worker backend:

- `cloudflare/worker.js`
- `cloudflare/schema.sql`
- `wrangler.toml`
- `CLOUDFLARE_DEPLOY.md`

Cloudflare-версия принимает запросы от сторонних приложений, принимает Telegram webhook, делает технический анализ и отправляет ответ в Telegram. Подробные шаги деплоя находятся в `CLOUDFLARE_DEPLOY.md`.

### Рекомендуемый вариант

Для этого проекта лучше всего подходит Docker-хостинг или VPS, потому что приложению нужен постоянный процесс для Telegram, локальная SQLite-база и Chromium для PDF.

Подготовленные файлы:

- `Dockerfile` - контейнер с Python и Chromium.
- `docker-compose.yml` - запуск на VPS.
- `render.yaml` - быстрый деплой на Render с persistent disk.

### Запуск через Docker на сервере

```bash
git clone https://github.com/FedotovDmitriy/stock-signal-scanner.git
cd stock-signal-scanner
docker compose up -d --build
```

После запуска откройте:

```text
http://SERVER_IP:8787
```

Данные приложения сохраняются в папке:

```text
./data
```

Там будут `app_settings.json`, `requests.db` и PDF-отчёты. Эта папка не должна попадать в GitHub.

### Render

1. Создайте новый Web Service из репозитория `FedotovDmitriy/stock-signal-scanner`.
2. Выберите Docker runtime.
3. Render прочитает `render.yaml`.
4. После деплоя откройте URL сервиса.
5. Введите Telegram token, Chat ID, Webhook/API token и API-ключи в интерфейсе.
6. Нажмите `Сохранить ключи`.

### Переменные окружения

- `HOST=0.0.0.0` - для сервера.
- `PORT` - обычно задаётся хостингом автоматически.
- `DATA_DIR=/app/data` - папка для базы, настроек и отчётов.
- `FUNDREP_TEMPLATE_PDF` - необязательный путь к PDF-шаблону, если он будет нужен на сервере.

## Что внутри

- Таймфрейм выбирается в интерфейсе: `1m`, `5m`, `15m`, `30m`, `1h`, `1d`, `1wk`.
- Можно ввести один тикер или список тикеров через запятую/с новой строки.
- Стратегии: Trend Following, Breakout Trading, Volume Profile + AVWAP, Momentum Trading.
- Время начала и окончания анализа задаётся в полях `Начало` и `Конец`.
- Котировки загружаются через публичный chart API Yahoo Finance.
- Telegram отправляется через Bot API.
- `Chat ID` нужен для кнопки `Тест Telegram` и для отправки отчёта из веб-интерфейса.
- После каждого анализа бот отправляет одно сообщение: общий отчёт по тикерам и список найденных сигналов внутри него.
- После нажатия `Старт` бот слушает новые личные сообщения от пользователей. Пользователь может перейти из группы по ссылке в бота, написать `AAPL` или `AAPL, MSFT`, и получить отчёт в своём чате.
- Если пользователь напишет `FundRep AAPL`, бот создаст PDF-репорт по тикеру AAPL: разделы, метрики и объяснения будут заполнены по фундаментальным данным, где они доступны.
- Если пользователь напишет `PromtRep AAPL`, бот создаст PDF с полным промтом для Perplexity Finance по KPI-dashboard анализу тикера AAPL: Income Statement, Momentum, Valuation History, Capital & Conviction, графики, KPI-карточки и требование современного профессионального вида.
- В PromtRep указано, что итоговый отчёт должен быть подготовлен в PDF-формате. Для каждого KPI и пункта промт просит объяснить смысл показателя, на что он влияет, возможные причины изменения и что инвестору отслеживать дальше.
- Для генерации PDF нужен установленный Google Chrome или Microsoft Edge.
- Источник фундаментальных данных выбирается в интерфейсе: `Auto`, `Financial Modeling Prep`, `Alpha Vantage`, `Polygon.io`, `Finnhub`, `Twelve Data`, `Yahoo paid API` или `Yahoo fallback`.
- В режиме `Auto` FundRep собирает отчёт по принципу дополнения: если первый источник не дал часть метрик, приложение пробует следующий источник и заполняет пустые поля, пока не соберёт максимум доступных данных.
- API-ключи и настройки сохраняются локально в `app_settings.json`; их можно поменять в интерфейсе и снова нажать `Сохранить ключи` или `Старт`.
- В интерфейсе есть блок `Логи запросов`: видно, откуда пришёл запрос, какие тикеры запрошены, действие и статус. Для Telegram доступны chat id, user id, username, имя, тип чата и язык. Telegram не передаёт IP или физический адрес; адрес возможен только если пользователь сам отправит геолокацию.
- Источники данных и технические ошибки не показываются в PDF FundRep, они остаются только в логах.
- Логи запросов сохраняются в локальную SQLite-базу `requests.db`. Кнопка `Очистить` удаляет записи из этой базы.
- Блок `Результаты` накапливает последние результаты по тикерам: новый запрос добавляет новые тикеры и обновляет уже существующие.
- Другой сервер может отправлять тикеры на `POST /api/external/analyze` или `POST /api/webhook/analyze`; приложение сделает анализ по сохранённым настройкам и отправит отчёт в Telegram.
- `app_settings.json` добавлен в `.gitignore`, но это обычный локальный текстовый файл, поэтому не отправляйте его другим людям.
- В отчёте используются стрелки: `🟢⬆️` если цена выше предыдущей свечи, `🔴⬇️` если ниже.
- Слишком длинные или некорректные тикеры не отправляются в Yahoo Finance, а показываются в разделе ошибок отчёта.

## Telegram

## Внешний сервер

1. В интерфейсе заполните `Bot token`, `Chat ID` и `Webhook/API token для внешнего сервера`.
2. Нажмите `Сохранить ключи`.
3. Если запросы будут приходить с другого компьютера, запускайте приложение так, чтобы оно слушало внешний интерфейс:

```powershell
$env:HOST="0.0.0.0"
python app.py
```

4. С другого сервера отправьте запрос:

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri "http://IP_ЭТОГО_СЕРВЕРА:8787/api/external/analyze" `
  -Headers @{ "X-Scanner-Token" = "ВАШ_WEBHOOK_TOKEN" } `
  -ContentType "application/json" `
  -Body '{"ticker":"AAPL"}'
```

Можно отправлять список:

```json
{"tickers":"AAPL, MSFT, NVDA"}
```

Также поддерживается заголовок `Authorization: Bearer ВАШ_WEBHOOK_TOKEN`.

1. Создайте бота через `@BotFather`.
2. Скопируйте токен в поле `Bot token`.
3. Узнайте `Chat ID` вашего чата или канала.
4. Нажмите `Тест Telegram`.
5. Если тест пришёл, нажмите `Анализ сейчас` или `Старт`.
6. Чтобы запускать анализ из Telegram, после `Старт` напишите боту тикер: `AAPL` или список: `AAPL, MSFT`.
7. Чтобы получить PDF-отчёт по фундаментальным KPI, напишите боту команду с тикером: `FundRep AAPL`.
8. Чтобы получить PDF с полным промтом для Perplexity, напишите: `PromtRep AAPL`.

## Ссылка на бота из группы

Добавьте в группу ссылку вида:

```text
https://t.me/USERNAME_ВАШЕГО_БОТА
```

Пользователь открывает ссылку, нажимает `Start`, пишет тикер и получает отчёт в личном чате с ботом.

Пример сообщения:

```text
📈 Сигнал по AAPL

Стратегия: Trend Following
Цена: 192.40
Условие: цена выше EMA200 и выше AVWAP
Идея: возможный long
Стоп: 187.50
Цель: 201.00
Риск: 1%
```

Это приложение помогает мониторить условия стратегии и не является финансовой рекомендацией.
