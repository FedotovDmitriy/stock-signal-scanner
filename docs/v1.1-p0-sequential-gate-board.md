# v1.1 P0 Sequential Gate Board

Updated: 2026-07-14

## Mandatory Workflow Rule

This board is the source of truth for the current v1.1 P0 closeout.
It supersedes the older gate numbering in `docs/v1.1-closeout-and-v1.2-transition-tasks.md` for this P0 flow.

1. Only one gate may be active at a time.
2. A specialist starts only after the previous gate has a documented `PASS` in this file.
3. `DONE`, `READY`, partial success, or local tests alone do not open the next gate. Only `PASS` does.
4. A `FAIL` or `BLOCKED` result stops the sequence. The manager assigns a correction and the same gate is repeated.
5. Production must not be changed by any gate on this board.
6. Secrets, HMAC signatures, service tokens, raw auth headers, and Telegram tokens must not be recorded here.
7. The manager makes the v1.1 decision only after every required gate is `PASS`.
